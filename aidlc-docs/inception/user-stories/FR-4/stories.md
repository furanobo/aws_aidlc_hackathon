# ユーザーストーリー — FR-4: ぶたアバター育成システム

## 概要

- **ペルソナ**: 田中太郎（29歳、全方位ダメ社会人）— 参照: `personas.md`
- **分解アプローチ**: ユーザージャーニーベース
- **受け入れ基準**: チェックリスト形式
- **設計原則**: 自堕落な行動を肯定し、自己嫌悪感を一切抱かせない

---

## ユーザージャーニー全体像

```text
行動記録(FR-2) → スコア計算 → ぶた成長 → ビジュアル変化 → 進化 → バトル準備(FR-5)
                                  ^                                    |
                                  |    減衰（ダメ行動がないと弱体化）    |
                                  +------------------------------------+
```

---

## Story 1: ぶたとの出会い（初期アバター生成）

**As a** ダメ人間プレイヤー
**I want to** アカウント作成後に自分だけのぶたアバターを受け取りたい
**So that** 「こいつを最高にダメなぶたに育てるぞ」というモチベーションが生まれる

### 受け入れ基準
- [ ] 初回ログイン時にぶたアバターが自動生成される
- [ ] 初期状態は「やせぶた」（最弱状態）で、寂しそうな表情をしている
- [ ] 「このぶたはあなたのダメさで幸せになります」的なウェルカムメッセージが表示される
- [ ] ぶたにニックネームをつけられる
- [ ] AI生成画像で初期ぶたのビジュアルが表示される

---

## Story 2: ダメ行動でぶたが喜ぶ（スコア計算・成長）

**As a** ダメ人間プレイヤー
**I want to** 自堕落な行動を記録するとぶたが嬉しそうに反応し、ステータスが上がるのを見たい
**So that** 「ダメな自分でもぶたを幸せにできている」という肯定感を得られる

### 受け入れ基準
- [ ] 不健康行動の記録（FR-2連携）に応じて不健康度ポイントが加算される
- [ ] ポイントは行動カテゴリ × 時間帯 × 頻度で変動する
  - 例: 深夜帯（22:00-4:00）の暴食は通常の1.5倍ポイント
  - 例: 3日連続夜更かしで連続ボーナス
- [ ] ポイント加算時にぶたが喜ぶリアクション（表情変化）が表示される
- [ ] 「ぶたが喜んでいます！」等のポジティブなフィードバックメッセージが出る
- [ ] ステータス（体重、幸福度、戦闘力）が数値で確認できる
- [ ] ヘルスケアアプリ（HealthKit/Health Connect）からの自動同期データもポイントに反映される
- [ ] ユーザーの手動入力は食事画像のみ、それ以外は自動同期

---

## Story 3: ぶたが太っていく（ビジュアル変化）

**As a** ダメ人間プレイヤー
**I want to** ぶたの見た目がどんどん丸く幸せそうに変化していくのを見たい
**So that** 自分のダメさが視覚的に「成果」として実感でき、達成感を得られる

### 受け入れ基準
- [ ] ステータス変化に応じてぶたのビジュアルが段階的に変化する
- [ ] 日次で表情・サイズなど軽微なビジュアル変化が反映される
- [ ] 体重増加に伴い、ぶたが丸くなり、表情がより幸せそうになる
- [ ] ステータス画面で数値（体重、幸福度、戦闘力）とビジュアルを並べて確認できる
- [ ] ビジュアル変化は常にポジティブな方向（太る＝幸せ、丸い＝かわいい）で表現される

---

## Story 4: ぶたが進化する（進化システム）

**As a** ダメ人間プレイヤー
**I want to** 一定条件を満たすとぶたが新しい姿に進化するのを体験したい
**So that** 「もっとダメになればもっとすごい進化が見られる」という期待感でプレイを続けたくなる

### 受け入れ基準
- [ ] 複数の不健康要素（食事、睡眠、運動、スクリーンタイム）の組み合わせで進化先が決まる
- [ ] 進化条件を満たすと進化演出が再生される
- [ ] 進化時にAI生成画像で新しいぶたのビジュアルが生成される
- [ ] 進化時にAI生成短動画クリップが再生される
- [ ] 進化後は見た目・ステータス・スキルが変化する
- [ ] 進化パスは複数存在し、どの「ダメさ」を極めるかで異なる進化先になる
  - 例: 食特化 → メガトンぶた、夜更かし特化 → ゾンビぶた、全方位 → 究極ダメぶた
- [ ] 進化履歴を確認できる（図鑑的な要素）
- [ ] 進化は不可逆（退化しない）で、達成感を損なわない

---

## Story 5: 真面目に生活するとぶたが元気をなくす（減衰・ペナルティ）

**As a** ダメ人間プレイヤー
**I want to** しばらくダメ行動をしないとぶたが寂しそうになり、ステータスが下がるのを見たい
**So that** 「ぶたのためにダメなことしなきゃ」という動機が生まれ、アプリを開き続ける

### 受け入れ基準
- [ ] 一定期間（例: 24時間）ダメ行動の記録がないとステータスが徐々に減衰する
- [ ] ヘルスケアアプリ連携で健康的な行動（例: 1万歩歩いた、早寝した）が検出されるとマイナスポイント
- [ ] 減衰時にぶたが寂しそうな表情になる（「お腹すいた...」「眠れない...」等）
- [ ] ペナルティの表現は「ぶたが悲しんでいる」であり、ユーザーを責める表現は一切使わない
- [ ] 減衰・ペナルティの通知は「ぶたがあなたを待っています」等、ぶた視点のポジティブな表現
- [ ] 進化は不可逆だが、ステータス数値は減衰する（進化段階は下がらない）

---

## Story 6: スコアの詳細を確認する（スコアシステム）

**As a** ダメ人間プレイヤー
**I want to** 自分の不健康度ポイントの内訳や履歴を確認したい
**So that** 「どのダメ行動が一番ぶたを喜ばせているか」を把握し、戦略的にダメになれる

### 受け入れ基準
- [ ] 不健康度ポイントの合計と内訳（カテゴリ別）が確認できる
- [ ] 時間帯ボーナス（深夜帯など）の適用状況が表示される
- [ ] 連続記録ボーナス（3日連続夜更かし等）の状況が表示される
- [ ] 日別・週別のポイント推移グラフが確認できる
- [ ] 表示は「不健康度」ではなく「ぶた幸福度貢献ポイント」等のポジティブな名称を使う

---

## Story 7: ぶたのステータスを確認する（ステータス画面）

**As a** ダメ人間プレイヤー
**I want to** ぶたの現在のステータス（体重、幸福度、戦闘力、スキル）を一覧で確認したい
**So that** バトル（FR-5）に向けた準備状況を把握できる

### 受け入れ基準
- [ ] ぶたのAI生成画像とステータス数値が1画面で確認できる
- [ ] 表示項目: 体重、幸福度、戦闘力（HP、攻撃力、防御力）、スキル一覧
- [ ] 現在の進化段階と次の進化条件の進捗が表示される
- [ ] スキルはタップで詳細説明が確認できる

---

## Story 8: 進化時の演出を楽しむ（AI生成動画）

**As a** ダメ人間プレイヤー
**I want to** 進化時にかっこいい（かわいい）動画演出を見たい
**So that** 進化の達成感が最大化され、SNSでシェアしたくなる

### 受け入れ基準
- [ ] 進化条件達成時にAI生成短動画クリップ（3-5秒程度）が自動再生される
- [ ] 動画は進化前→進化後の変身演出を含む
- [ ] 動画生成中はローディング演出が表示される（待ち時間のストレス軽減）
- [ ] 生成された動画は保存され、後から再生できる
- [ ] 動画生成に失敗した場合は静止画のビフォーアフターで代替表示される

## 心理設計原則（全ストーリー共通）

本アプリは「人をダメにするサービス」だが、ユーザーに自己嫌悪感を抱かせてはならない。

1. **肯定のみ**: すべてのフィードバックは「ぶたが喜んでいる」視点。ユーザーの行動を直接評価しない
2. **罪悪感の変換**: 「深夜ラーメン食べちゃった...」→「ぶたが大喜び！+150pt」に変換
3. **責めない減衰**: ステータス低下時も「ぶたがお腹すいた」であり「あなたが怠けている」ではない
4. **達成感の保証**: 進化は不可逆。一度手に入れた進化は失われない
5. **ユーモア**: 全体のトーンはコミカルで軽い。深刻さを排除する
