# ペルソナ定義

## テーマ

**「人をダメにするサービス」** — 自堕落な生活を送るほどゲーム内のぶたが幸せに太り強くなる逆転発想アプリ

---

## Persona 1: 田中 太郎（たなか たろう）— 全方位ダメ社会人

### 基本情報

| 項目 | 内容 |
|------|------|
| 年齢 | 29歳 |
| 職業 | IT企業の中堅エンジニア |
| 居住 | 東京都内、1Kマンション一人暮らし |
| 年収 | 450万円 |

### ダメ人間プロフィール

**食のダメさ:**
- 平日の夕食は毎日コンビニ弁当かUber Eats
- 金曜深夜の背脂ラーメンが至福の時間
- 冷蔵庫の中身はビールとエナジードリンクだけ
- 週末はポテチとコーラで一日過ごすことも

**生活リズムのダメさ:**
- 平日は深夜2時就寝、朝9時ギリギリ起床
- 休日は昼過ぎまで寝て、そのまま二度寝
- 目覚ましを5回スヌーズしてやっと起きる
- 「明日から早起きする」が口癖

**デジタル依存のダメさ:**
- スマホのスクリーンタイムは1日平均7時間
- YouTubeのおすすめ動画を延々と見続ける
- SNSを無意識にリフレッシュし続ける
- 寝る前のスマホが止められない

**運動不足:**
- 最寄り駅まで徒歩5分すら面倒でタクシーを使う
- ジムの会員証は財布の肥やし（半年未使用）
- エレベーターがあれば絶対に階段を使わない
- 1日の歩数は平均2,000歩以下

### 動機・心理

- **罪悪感**: 自堕落な生活に薄々罪悪感はあるが、やめられない
- **自己肯定感**: 健康アプリを入れても「お前はダメだ」と言われている気がして続かない
- **承認欲求**: ダメな自分を否定されるのではなく、肯定してほしい
- **競争心**: 友人より強いキャラを持ちたい。そのためならもっとダメになれる

### このアプリとの関わり方

- 深夜ラーメンを食べた後、嬉しそうに太るぶたを見てニヤニヤする
- 「今日も一日ダメだった」が「今日も一日ぶたを育てた」に変わる
- バトルで勝つために意図的に夜更かしやジャンクフードを選ぶようになる
- 友人と「俺のぶたの方が太ってる」と自慢し合う

### 典型的な1日

```text
09:00  スヌーズ5回目でやっと起床（睡眠不足 +ポイント）
09:05  ベッドでスマホ30分（スクリーンタイム +ポイント）
09:40  朝食抜きで出勤（食事スキップ +ポイント）
12:00  コンビニでカップ麺+おにぎり2個（ジャンクフード +ポイント）
19:00  退勤、エレベーターで降りる（運動不足 +ポイント）
19:30  Uber Eatsでピザ注文（暴食 +ポイント）
20:00  YouTube視聴開始（スクリーンタイム +ポイント）
23:00  「もう寝よう」→ SNS巡回開始
01:30  深夜ラーメン（深夜飯 +ボーナスポイント）
02:00  就寝（夜更かし +ポイント）
```

→ この1日でぶたは大満足。幸福度MAX、体重増加、戦闘力アップ。
