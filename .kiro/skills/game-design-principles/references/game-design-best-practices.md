# ゲームデザイン ベストプラクティス

> 「良いゲーム」とは何か。プリミティブな設計原則。

---

## 1. コアループの三原則

良いゲームは30秒で楽しい。

```
ACTION（行動）→ FEEDBACK（応答）→ REWARD（報酬）→ REPEAT
```

| 原則 | 説明 | 違反例 |
|------|------|--------|
| 即時性 | 行動から報酬まで0.5秒以内 | 10秒待たないと結果が出ない |
| 明瞭性 | 何が起きたか一目でわかる | 数値だけ変わって実感がない |
| 漸進性 | 繰り返すほど少しずつ変化する | 100回やっても何も変わらない |

---

## 2. プレイヤーモチベーションの4類型

| 類型 | 求めるもの | 設計で応える方法 |
|------|-----------|----------------|
| Achiever（達成者） | 目標達成、コンプリート | 明確なマイルストーン、収集要素 |
| Explorer（探索者） | 発見、未知との遭遇 | 隠し要素、予測不能な進化 |
| Socializer（社交者） | 他者との繋がり | 共有機能、フレンド対戦 |
| Killer（競争者） | 他者に勝つ快感 | ランキング、対戦システム |

**設計指針**: 1つの類型に特化せず、コアターゲット1類型 + サブ1類型を狙う。

---

## 3. 報酬スケジュール設計

| スケジュール | 効果 | 適用場面 |
|-------------|------|---------|
| 固定間隔 | 予測可能な安心感 | レベルアップ、マイルストーン報酬 |
| 変動比率 | 中毒性が最も高い | ドロップ報酬、進化分岐 |
| 固定比率 | 努力に比例する公平感 | ポイント累積、実績解除 |

**黄金比**: 固定報酬70% + 変動報酬30%。基盤の安心感の上にサプライズを載せる。

## 4. フロー状態の維持

```
難易度
  ↑
  │  不安ゾーン（難しすぎる → 離脱）
  │  ─────────────────────
  │  フローゾーン（ちょうどいい → 没入）
  │  ─────────────────────
  │  退屈ゾーン（簡単すぎる → 離脱）
  └──────────────────────→ プレイヤースキル
```

| 戦略 | 実装方法 |
|------|---------|
| 動的難易度調整 | プレイヤーの行動パターンに応じて自動調整 |
| 選択による難易度 | プレイヤー自身が難易度を選べる |
| 失敗コストの最小化 | 失敗しても大きなペナルティがない |

## 5. プログレッション（進行感）の設計

### 5.1 4種のプログレッション

| 種類 | 何が進むか | プレイヤーの実感 |
|------|-----------|----------------|
| スキル進行 | プレイヤー自身がうまくなる | 「自分が成長した」 |
| パワー進行 | キャラクターが強くなる | 「数値が育った」 |
| コンテンツ進行 | 新しい要素が解放される | 「次は何があるんだろう」 |
| ストーリー進行 | 物語が展開する | 「続きが気になる」 |

### 5.2 ペーシングの鉄則

1. **最初の5分で勝利体験を与える**（フック）
2. **徐々にチャレンジを増やす**（登坂）
3. **緊張と弛緩を繰り返す**（波）
4. **意味のある選択を定期的に挟む**（分岐）

## 6. 継続率を決める心理設計

| 心理原則 | ゲーム設計への応用 |
|---------|------------------|
| 損失回避 | 「明日ログインしないとXが消える」より「明日はXがもらえる」 |
| サンクコスト | 育てたキャラへの愛着が離脱を防ぐ |
| 社会的証明 | 「他のプレイヤーもやっている」が安心感を生む |
| 内発的動機 | 義務感ではなく好奇心・愛着で動かす |
| 自己決定感 | 強制されず「自分で選んだ」と感じさせる |

**最重要**: 義務感で動かすゲームは3ヶ月で死ぬ。愛着と好奇心で動かすゲームは年単位で続く。

---

## 7. バランシングの原則

| 原則 | 値の目安 | 理由 |
|------|---------|------|
| ワンパン禁止 | 一撃死確率 < 5% | 理不尽感は即離脱に直結 |
| 逆転可能性 | HP30%でも勝率20%+ | 最後まで諦めない動機 |
| 試合時間 | 2-4分 | カジュアル層の集中力限界 |
| 先攻有利幅 | < 10% | 運ゲー感を排除 |
| レベル差影響 | ±5Lvで勝率55-65% | スキルで覆せる程度 |

---

## 8. アンチパターン

| ❌ やってはいけない | ✅ こうする | 理由 |
|-------------------|-----------|------|
| 罰で行動を強制する | 報酬で行動を誘引する | 罰は怒りと離脱を生む |
| 最初からすべて見せる | 徐々に解放する | 情報過多は混乱を生む |
| 毎日のノルマを課す | いつ戻っても歓迎する | 義務感はストレスになる |
| 課金者だけ強い | 時間投資でも強くなれる | 不公平感は離脱を生む |
| 1つの正解だけ用意する | 複数の戦略を許容する | 個性が出ないと飽きる |

## 9. 「良いゲーム」チェックリスト

- [ ] 30秒で1回「楽しい」が発生するか
- [ ] プレイヤーが「次はどうなる？」と思うか
- [ ] 負けても「もう1回やろう」と思えるか
- [ ] 1週間ぶりに戻っても居場所があるか
- [ ] 友達に見せたくなる瞬間があるか
- [ ] プレイヤーに「自分で選んだ」と感じさせているか
- [ ] 義務感ではなく好奇心で動かしているか
