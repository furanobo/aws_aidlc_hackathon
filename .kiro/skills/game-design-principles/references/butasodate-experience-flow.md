# ぶたそだて 推奨ゲーム体験フロー

> インストールから「もう手放せない」に至るまでの理想的なプレイヤージャーニー。

---

## 1. 体験フロー全体像

```
[インストール] → [初回起動] → [ぶた誕生] → [最初の記録]
       ↓
[初成長体験] → [自動検出に気づく] → [進化への期待]
       ↓
[第1進化] → [バトル解放] → [初バトル] → [フレンド招待]
       ↓
[進化パス分岐] → [やりこみ・収集] → [日常化]
```

---

## 2. フェーズ別体験設計

### Phase 0: インストール〜初回起動（0-30秒）

| ステップ | 体験 | 設計意図 |
|---------|------|---------|
| アプリ起動 | スプラッシュ画面にぶたが一瞬映る | 期待感の醸成 |
| 認証 | Google/Xワンタップ or メール | 3秒以内に突破。摩擦ゼロ |
| ニックネーム設定 | 1画面、1入力、1ボタン | 即完了 |

**目標**: 起動から30秒以内に「ぶた」に出会わせる。

---

### Phase 1: ぶた誕生（30秒-2分）

| ステップ | 体験 | プレイヤーの感情 |
|---------|------|----------------|
| 卵（or 泥）からぶた出現 | かわいい初期ぶたが画面に現れる | 「お、かわいい」 |
| ぶたが自己紹介 | 「ボクを太らせて！」的セリフ | 「何これ面白い」 |
| ヘルスデータ連携提案 | 「キミの怠惰、自動で感知するよ？」 | 「便利そう、許可しよ」 |

**目標**: 2分以内に愛着の種を植える。

---

### Phase 2: 最初の記録体験（2-5分）

| ステップ | 体験 | プレイヤーの感情 |
|---------|------|----------------|
| チュートリアル | 「昨日なんかダメなことした？」 | 「あー、深夜にラーメン食べた…」 |
| 3タップ記録 | カテゴリ選択 → サブカテゴリ → 記録！ | 「え、これだけ？」 |
| 即時フィードバック | ぶたが喜ぶ＋ポイント加算＋ちょっと太る | 「ぶた嬉しそうwww」 |
| 追加記録の提案 | 「他にもある？」 | 「あ、夜更かしもしたわ」 |

**目標**: 「不健康を記録する＝楽しい」を5分以内に体感させる。

---

### Phase 3: 自動検出への気づき（翌日）

| ステップ | 体験 | プレイヤーの感情 |
|---------|------|----------------|
| アプリ起動時サマリー | 「昨日2000歩しか歩いてないね！」 | 「バレてるwww」 |
| 自動ポイント加算 | 何もしてないのにぶたが成長 | 「勝手に育つの最高」 |
| ぶたのコメント | 「サボってくれてありがとう♪」 | 「かわいい」 |

**目標**: 「何もしなくても育つ」＝ 離脱しない構造をここで植え付ける。

---

### Phase 4: 成長の加速と進化への期待（3日-1週間）

| ステップ | 体験 | プレイヤーの感情 |
|---------|------|----------------|
| レベルアップ演出 | Lv5, Lv8... と上がっていく | 「おー、順調に育ってる」 |
| ぶたの見た目がじわじわ変化 | 少しずつ丸くなる | 「太ってきたwww」 |
| 進化の予兆表示 | 「何かが起こりそう…？」（Lv9辺り） | 「え、何？進化するの！？」 |

**目標**: 「次に何が起こるか」の好奇心で1週間つなぐ。

---

### Phase 5: 第1進化（1-2週間目）

| ステップ | 体験 | プレイヤーの感情 |
|---------|------|----------------|
| 進化条件達成 | Lv10到達＋カテゴリ比率で分岐 | 「おおっ！」 |
| 進化演出 | AI生成動画クリップで変身シーン | 「すげぇ！グルメぶただ！」 |
| 新スキル習得 | 「深夜ラーメンスプラッシュを覚えた！」 | 「技名www」 |
| バトル機能解放 | 「この力、試してみない？」 | 「バトルできるの！？」 |

**目標**: 進化の達成感 → バトルへの好奇心 を一気に繋ぐ。

---

### Phase 6: 初バトル体験（進化直後）

| ステップ | 体験 | プレイヤーの感情 |
|---------|------|----------------|
| ランダムマッチ | 「ぶたバトル、いくぞ！」 | ドキドキ |
| 対戦相手表示 | 相手の進化形態が見える | 「あいつ夜型ぶただ…」 |
| ターン操作 | スキル選んでぶつける | 「深夜ラーメン！くらえ！」 |
| 勝利/敗北 | 結果＋ランキングpt変動 | 勝ち→「最高！」/ 負け→「もっと太らせなきゃ」 |

**目標**: 勝っても負けても「もう1回」or「もっと育てよう」になる。

---

### Phase 7: ソーシャル拡散（2-3週間目）

| ステップ | 体験 | プレイヤーの感情 |
|---------|------|----------------|
| スクリーンショット共有 | 進化ぶたの画像が映える | 「友達に見せたいwww」 |
| フレンド招待 | 「お前もぶた育てろよ」 | 布教の喜び |
| フレンド対戦 | 知り合い同士で殴り合い | 「お前の方がデブぶただろww」 |

**目標**: 1人のプレイヤーが1-2人を連れてくる構造。

---

### Phase 8: 日常化とやりこみ（1ヶ月〜）

| 体験 | 継続動機 |
|------|---------|
| 毎日の自動検出 | 何もしなくてもぶたが反応する |
| 第2進化への期待 | 次はどんな姿になるのか |
| ランキング変動 | 順位の上下が気になる |
| 新しい進化パス発見 | 「こんなのいるの！？」→ 収集欲 |
| フレンド対戦の日常化 | 「今日のぶた見せろよ」 |

---

## 3. 離脱防止のセーフティネット

| 離脱リスク | 対策 |
|-----------|------|
| 初日で飽きる | 5分以内に報酬体験を3回与える |
| 3日放置 | 起動時に「Xポイント溜まってたよ！」と表示（自動検出の恩恵） |
| 1週間放置 | 復帰時にまとめて成長＋「寂しかった…」演出（罰ではない） |
| バトルで連敗 | 敗北pt減少は勝利pt増加より小さい＋負けても「ぶたは元気」 |
| 進化がマンネリ | 第2進化の条件は予告なしで「発見」させる |

---

## 4. コアループ（日常プレイ）

```
朝起動 → サマリー確認（自動検出結果）→ ぶたの反応を見る
    ↓
日中 → 思い出したら手動記録（深夜ラーメンの記録は翌朝でもOK）
    ↓
気が向いたら → バトル1-2戦（2-3分/戦）
    ↓
翌朝 → 繰り返し（何もしなくてもぶたは育つ）
```

**所要時間**: 1日30秒〜3分。怠惰ユーザーは30秒で完結する。
