# ぶたそだて ステータス仕様・バトル仕様・感情曲線

> 数値設計と、それがプレイヤーの感情にどう作用するかの包括リファレンス。

---

## 1. ステータス仕様

### 1.1 基本ステータス

| ステータス | 略称 | 役割 | バトルでの効果 |
|-----------|------|------|---------------|
| HP | HP | 体力 | 0になったら敗北 |
| 攻撃力 | ATK | 打撃力 | ダメージ計算の基礎値 |
| 防御力 | DEF | 耐久力 | 被ダメージ軽減 |
| 素早さ | SPD | 行動速度 | ターン内の行動順決定 |

### 1.2 ヘルスデータ → ステータス対応

| ヘルスデータ | 検出される不健康行動 | 主上昇ステータス | 副上昇 | 設計根拠 |
|---|---|---|---|---|
| 体重増加 | +1kg以上 | HP +20pt | DEF +3 | 重い＝タフ |
| 歩数不足 | <8000歩/日 | DEF +5〜12 | HP +2 | 動かない＝硬い |
| 夜更かし | 就寝 >23:00 | SPD +8〜14 | ATK +2 | 夜行性＝素早い |
| 睡眠不足 | <7時間 | ATK +6〜10 | SPD +2 | 寝不足＝キレやすい |
| 寝すぎ | >9時間 | HP +4〜8 | DEF +2 | よく寝る＝回復力 |
| 手動記録（食事系） | 深夜ラーメン等 | ATK +10〜15 | HP +3 | エネルギー＝パワー |
| 手動記録（生活系） | 二度寝、サボり等 | DEF +10〜15 | SPD +3 | 怠惰＝守備的 |

### 1.3 ステータス成長曲線

**対数曲線を採用**:

```
stat_value = base + coefficient × log₂(1 + category_points / scale)
```

| パラメータ | HP | ATK | DEF | SPD |
|-----------|-----|-----|-----|-----|
| base | 50 | 10 | 10 | 10 |
| coefficient | 55 | 9 | 9 | 9 |
| scale | 100 | 80 | 80 | 80 |
| 理論最大値 | 600 | 100 | 100 | 100 |

```
ステータス値
  ↑
600│                    ___________________
   │                 /
   │              /
350│           /
   │        /         ← 序盤に急成長、後半は緩やか
200│     /
   │   /
 50│__/
   └──────────────────────────────────→ 累積カテゴリポイント
   0    500   1000  2000  3000  5000
```

**なぜ対数か**:
- 序盤: 1回の記録でぐんぐん上がる → 即時の報酬感
- 中盤: 着実に成長を実感 → 継続動機
- 終盤: 天井付近 → バトルバランスの安定

### 1.4 レベルシステム

| レベル帯 | 必要累積ポイント | HP目安 | ATK/DEF/SPD目安 |
|---------|----------------|--------|----------------|
| 1-5 | 0-100 | 50-120 | 10-25 |
| 6-10 | 100-500 | 120-200 | 25-45 |
| 11-20 | 500-2000 | 200-350 | 45-70 |
| 21-30 | 2000-5000 | 350-500 | 70-90 |
| 31+ | 5000+ | 500-600 | 90-100 |

レベルアップ閾値: `required_points = 20 × level^1.3`（序盤サクサク、後半じっくり）

### 1.5 ポイント加算・減算テーブル

**加算（不健康行動）**:

| 行動 | 基本ポイント | 変動条件 |
|------|------------|---------|
| 手動記録（食事系） | 12pt | - |
| 手動記録（生活系） | 10pt | - |
| 体重 +1kg | 20pt | +1kgごとに+20 |
| 歩数不足 | 5-12pt | 0歩=12pt, 4000歩=5pt（線形補間） |
| 夜更かし | 8pt + 3pt/h | 23:00基準、超過時間に比例 |
| 睡眠不足 | 6pt + 2pt/h | 7h基準、不足時間に比例 |
| 寝すぎ | 4pt + 1pt/h | 9h基準、超過時間に比例 |

**減算（健康行動）**: 加算の50-70%

| 行動 | 減算ポイント | 演出 |
|------|------------|------|
| 体重 -1kg | -10pt | ぶた「ちょっと痩せちゃった…」 |
| 歩数 >8000歩 | -3〜-8pt | ぶた「疲れた…」 |
| 早寝（<23:00） | -4pt | ぶた「もう寝るの…？」 |
| 適正睡眠 | -3pt | ぶた「健康的すぎる…」 |

## 2. 進化仕様

### 2.1 進化パス構造

```
           [初期ぶた Lv1]
                │
          [Lv10 第1進化]
          /      |      \
     食事型    睡眠型   運動不足型
    グルメぶた  夜型ぶた  ごろごろぶた
        │        │        │
   [Lv20 第2進化] [Lv20]   [Lv20]
    /     \    /    \    /     \
  暴食王 美食家 不眠番長 惰眠王 仙人ぶた 巨岩ぶた
```

### 2.2 進化条件

| 進化先 | レベル条件 | カテゴリ比率 | 追加条件 |
|--------|-----------|------------|---------|
| グルメぶた | Lv10+ | 食事系pt ≥ 40% | なし |
| 夜型ぶた | Lv10+ | 睡眠系pt ≥ 40% | なし |
| ごろごろぶた | Lv10+ | 運動系pt ≥ 40% | なし |
| 暴食王 | Lv20+ | 食事系pt ≥ 50% | 手動記録50回以上 |
| 美食家 | Lv20+ | 食事系pt ≥ 50% | 手動記録50回未満 |
| 不眠番長 | Lv20+ | 睡眠系pt ≥ 50% | 夜更かし平均1:00以降 |
| 惰眠王 | Lv20+ | 睡眠系pt ≥ 50% | 寝すぎ回数 > 夜更かし回数 |
| 仙人ぶた | Lv20+ | 運動系pt ≥ 50% | 歩数0-1000歩の日が10日+ |
| 巨岩ぶた | Lv20+ | 運動系pt ≥ 50% | 平均歩数3000歩以下 |

### 2.3 退化条件

- 累積ポイントが現在の進化段階の必要ポイントの**70%を下回る**と退化
- 退化は1段階ずつ（第2→第1→初期）
- 退化演出: コミカルに「ぶたが健康になっちゃった」

### 2.4 進化時ボーナス

| ボーナス | 内容 |
|---------|------|
| HP全回復 | バトル中でなければ即全回復 |
| ステータス一括上昇 | 全ステータス +10% |
| 新スキル習得 | 進化パス固有スキル1つ |
| ビジュアル変化 | AI生成画像が大きく変わる |

## 3. バトル仕様

### 3.1 基本ルール

| 項目 | 仕様 |
|------|------|
| 形式 | ターン制（同時選択 → 素早さ順行動） |
| ターン制限 | 20秒（超過で自動防御） |
| バトル時間制限 | 5分 |
| 時間切れ判定 | 残りHP割合が高い方の勝利 |
| 同率時 | 引き分け（ランキングpt変動なし） |
| 操作 | スキル（最大4つ）/ 防御 / アイテム |
| 切断 | 切断した側の自動敗北 |

### 3.2 ダメージ計算式

```
base_damage = skill_power × (ATK / DEF_opponent) × type_modifier
final_damage = base_damage × (0.85 + random(0.3))  # 乱数幅±15%
```

| 要素 | 説明 |
|------|------|
| skill_power | スキル固有の威力値（30-120） |
| ATK/DEF比 | 攻撃側ATK ÷ 防御側DEF |
| type_modifier | 進化タイプ相性（0.8〜1.2） |
| 乱数 | ±15%のブレ（ワンパン防止） |

### 3.3 タイプ相性（緩やかな傾向差）

| 攻撃側 → 防御側 | 食事型 | 睡眠型 | 運動不足型 |
|---|---|---|---|
| **食事型** | ×1.0 | ×1.1 | ×0.9 |
| **睡眠型** | ×0.9 | ×1.0 | ×1.1 |
| **運動不足型** | ×1.1 | ×0.9 | ×1.0 |

**設計意図**: 完全三すくみ（×1.5等）にすると運ゲーになる。±10%なら「有利だけどスキル次第で逆転可能」。

### 3.4 スキル一覧

| スキル名 | タイプ | 威力 | 効果 | CT | 習得条件 |
|---------|--------|------|------|-----|---------|
| 深夜ラーメンスプラッシュ | ATK | 90 | 単発高火力 | 3T | グルメぶた進化 |
| 暴飲暴食チャージ | BUFF | - | 次ターンATK×1.5 | 2T | 食事系Lv10+ |
| 夜更かしの一閃 | ATK+SPD | 70 | 先制確定 | 3T | 夜型ぶた進化 |
| 二度寝バリア | DEF | - | ダメージ1回無効 | 5T | 睡眠系Lv15+ |
| 永遠のゴロ寝 | DEF | - | 2ターンDEF×2 | 4T | ごろごろぶた進化 |
| サボりカウンター | ATK | 60 | 被攻撃時に反撃 | 4T | 運動系Lv10+ |
| 惰眠の波動 | ATK | 50 | 相手SPD-20%（2T） | 3T | 睡眠系Lv10+ |
| 体重プレス | ATK | 80 | 自HP比例ダメージ | 3T | HP300以上 |
| たいあたり | ATK | 40 | 基本攻撃、CT無し | 0T | 初期習得 |
| まるまる | DEF | - | DEF+30%（1T） | 1T | 初期習得 |

### 3.5 防御アクション

- ダメージ50%軽減
- 20秒無操作時のデフォルト行動
- CT無し、毎ターン選択可能

### 3.6 バトルバランス設計値

| 指標 | 目標値 | 理由 |
|------|--------|------|
| 平均バトル時間 | 8-12ターン（2-3分） | カジュアル層の集中力 |
| ワンパン確率 | <5% | 理不尽感排除 |
| 先攻アドバンテージ | 5-10% | SPD特化が支配的にならない |
| HP30%からの逆転率 | 25%+ | 最後まで諦めない動機 |
| レベル±5差の勝率 | 55-65% | スキルで覆せる範囲 |

### 3.7 マッチメイキング

```
優先度1: 同レベル帯（±3） → 待ち0-10秒
優先度2: 近接レベル帯（±5） → 待ち10-20秒
優先度3: 拡張レベル帯（±10）→ 待ち20-30秒
タイムアウト: 30秒 →「見つかりませんでした」
```

### 3.8 ランキングポイント

```
勝利: +15〜+25pt（格上ほど多い）
敗北: -10〜-20pt（格下に負けるほど多い）
引き分け: ±0
切断負け: -20pt（ペナルティ込み）
切断勝ち: +0pt（ファーミング防止）
```

**非対称設計**: 負けの減少 < 勝ちの増加。「負けが怖い」を排除し、気軽にバトルさせる。

## 4. ユーザー感情曲線

### 4.1 初日〜1週間の感情推移

```
感情の高さ
(ポジティブ↑)
  ↑
  │    ②           ④         ⑥
  │   /\    ③    /\   ⑤    /\
  │  /  \  /\  /  \  /\  /  \    ← 波を作る
  │ /    \/  \/    \/  \/    \
  │/                            \___  ← 安定した満足感へ
  │①
  └─────────────────────────────────→ 時間
  初回  1日目  2日目  3日目  ...  1週間

① インストール（期待）
② ぶた誕生（愛着のピーク1）
③ 初めて自動検出に気づく（驚きと笑い）
④ 初レベルアップ（達成感）
⑤ 進化の予兆（期待感の高まり）
⑥ 第1進化（最大の感情ピーク）
```

### 4.2 各体験ポイントの感情マッピング

| 体験ポイント | 主感情 | 副感情 | デザインが狙うこと |
|---|---|---|---|
| ぶた誕生 | 愛着 | 好奇心 | 「この子を育てたい」 |
| 初めての記録 | 罪悪感の解放 | 笑い | 「不健康を記録していいんだ」 |
| ぶたが喜ぶ反応 | 達成感 | 愛着 | 「この子が喜ぶならもっと記録しよう」 |
| 自動検出サマリー | 驚き | 面白さ | 「バレてるwww でも怒られない」 |
| ぶたが「痩せちゃった」 | 損失感（軽い） | 笑い | 「あ、もっと太らせなきゃ」 |
| レベルアップ | 達成感 | 期待 | 「次は何が起こる？」 |
| 進化 | 驚き+達成感 | 所有欲 | 「俺だけのぶただ」 |
| 初バトル勝利 | 征服感 | 笑い | 「俺の怠惰が相手を倒した」 |
| 初バトル敗北 | 悔しさ（軽い） | 闘争心 | 「もっと太らせて強くするぞ」 |
| フレンドに見せる | 自慢 | 帰属感 | 「見ろよこのデブぶたwww」 |
| 退化（健康になる） | 焦り（コミカル） | 笑い | 「ヤバい、健康になってる」 |

### 4.3 感情の設計原則

| 原則 | 実装 | 従来の健康アプリとの違い |
|------|------|----------------------|
| **罰を与えない** | 健康行動は「ぶたが寂しがる」で表現 | 従来: 記録しないと叱る |
| **義務感を排除** | 何もしなくても自動検出で育つ | 従来: 毎日ログインを強制 |
| **笑いで包む** | 退化も進化もコミカルな演出 | 従来: 数値グラフで現実を突きつける |
| **損失感を愛着に変換** | 「ぶたが痩せる」→ 育てたい欲 | 従来: 「ストリーク途切れた」→ 罪悪感 |
| **社会的比較を楽しくする** | 「俺の方がデブぶた」＝自慢 | 従来: 「あいつより歩いてない」＝劣等感 |

### 4.4 感情曲線の長期設計（1ヶ月〜）

```
感情の高さ
  ↑
  │  進化①   進化②           新進化発見
  │   /\      /\               /\
  │  /  \  __/  \  ___________/  \___
  │ /    \/      \/                    ← 安定した愛着ベースライン
  │/
  └──────────────────────────────────→
  1週    2週     1ヶ月        2ヶ月+

長期の感情ベースライン:
- 「ぶたへの愛着」が定常的な幸福感を提供
- 進化・新発見がスパイク（変動報酬）
- バトルの勝ち負けが日常的な小さな波を作る
- 「何もしなくてもいい」安心感が離脱を防ぐ
```

### 4.5 ネガティブ感情の変換テーブル

| 現実の感情 | ゲーム内で変換される感情 | 変換メカニズム |
|-----------|----------------------|--------------|
| 「深夜にラーメン食べちゃった…」 | 「ぶたに良い餌あげた！」 | 罪悪感 → 貢献感 |
| 「今日全然歩いてない…」 | 「ぶたの防御力上がったな」 | 自己嫌悪 → 達成感 |
| 「また夜更かしした…」 | 「ぶたの素早さが育ってる」 | 後悔 → 面白さ |
| 「太ったかも…」 | 「ぶたのHP伸びてるじゃん」 | 不安 → ポジティブな解釈 |
| 「健康的に過ごしちゃった」 | 「ぶたが寂しそう、明日はサボろう」 | 健康への義務感 → ゲーム的動機 |

**核心**: このゲームはすべてのネガティブ感情を「ぶたのため」という文脈でポジティブに再解釈させる装置である。セルフコンパッション（自己への優しさ）をゲームメカニクスとして実装している。

## 5. まとめ: 設計の一貫性チェック

| チェック項目 | 合格基準 | 本設計 |
|---|---|---|
| 怠惰が報われるか | 不健康行動の方がポイント効率が良い | ✅ 加算 > 減算（50-70%ルール） |
| 罰がないか | ネガティブフィードバックが存在しない | ✅ 退化もコミカル演出 |
| 何もしなくても育つか | 自動検出だけで成長する | ✅ ヘルスデータ自動同期 |
| バトルが怖くないか | 負けのペナルティが軽い | ✅ 非対称ランキングpt |
| 友達に見せたいか | 共有欲を刺激する瞬間がある | ✅ 進化時のスクショ誘導 |
| 1週間空けても大丈夫か | 復帰時に罰がない | ✅ まとめて成長＋歓迎演出 |
