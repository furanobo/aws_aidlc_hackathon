# デモパート台本＆スライド構成（5分）

## デモの設計思想

**デモは「機能紹介」ではなく「物語」で見せる。**

主人公: ペルソナ「タケシ」（25歳会社員、不健康な生活をしている）
ストーリー: タケシの1日の堕落 → ぶたの成長 → 進化 → バトルで勝利

---

## 事前準備チェックリスト

- [ ] デモ用アカウント作成済み（Lv4、進化直前の状態に調整）
- [ ] カテゴリマスターデータ投入済み
- [ ] バトル用の対戦相手アカウント作成済み（別端末 or 自動マッチbot）
- [ ] ネットワーク安定確認（会場WiFi + テザリングバックアップ）
- [ ] 画面ミラーリング動作確認
- [ ] バックアップ動画（全フロー録画済み）USBに保存
- [ ] フォントサイズ・画面表示が遠くから見えるか確認

---

## タイムライン（5分）

```
0:00-0:20  デモ導入（スライド→実機に切り替え）
0:20-1:30  行動記録フロー（メインループ体験）
1:30-2:30  進化イベント発生
2:30-3:30  ステータス・スキル確認
3:30-4:40  バトルデモ
4:40-5:00  デモまとめ（スライドに戻る）
```

---

## 詳細台本

### 0:00-0:20 デモ導入

**スライド**: 「タケシの1日」（シンプルなイラスト or テキスト）

**台詞**:
「実際にお見せします。これはタケシ、25歳会社員。
今日も絶好調にダメな1日を送ります。」

**操作**: スライドから実機画面に切り替え

---

### 0:20-1:30 行動記録フロー（メインループ）

**画面**: ホーム画面 → 行動記録

**台詞と操作**:

「まずホーム画面。タケシのぶたがいます。今Lv4、あと少しで進化です。」
（ぶたのアイドルアニメーションを見せる。2秒待つ）

「さて、タケシは昨日こんな1日でした——」

**記録1: 深夜ラーメン**
「深夜2時にラーメン食べました。記録します。」
（「記録」ボタン → カテゴリ「深夜ラーメン」選択 → 確認 → 記録）
「はい、3タップ。+50ポイント。ぶたが喜んでます。」
（ぶたの喜びリアクション演出を見せる）

**記録2: 二度寝**
「今朝は二度寝もしました。」
（カテゴリ「二度寝」選択 → 記録）
「+30ポイント。どんどん不健康スコアが上がります。」

**記録3: 運動サボり**
「ジムは今月も行ってません。」
（カテゴリ「運動サボり」選択 → 記録）
「+40ポイント。合計ポイントがレベルアップラインを超えました——」

---

### 1:30-2:30 進化イベント

**画面**: 進化演出（フルスクリーンアニメーション）

**台詞**:
「おっ、来ました。進化です！」

（進化アニメーション再生。会場が見守る）

「タケシのぶた、食事系の記録が多かったので——
**『グルメぶた』に進化しました！**」

（進化後の姿を見せる。2秒間の余韻）

「見た目が変わり、ステータスも上がっています。
食事系の不健康に特化した進化パスです。
タケシの"ダメさの傾向"がそのままぶたのアイデンティティになる。」

（スキル習得通知を見せる）
「新スキル『暴食タックル』を習得！ これ、バトルで使えます。」

---

### 2:30-3:30 ステータス・スキル確認

**画面**: AvatarStatusPage

**台詞**:
「ステータス画面を見てみましょう。」

（アバタータップ → ステータス画面）

「HPと攻撃力が特に高い。食事系パスの成長曲線です。
レーダーチャートで一目で分かります。」

（スキルタブに切り替え）

「スキルは現在2つ。『暴食タックル』と『満腹バリア』。
不健康行動の名前がそのままスキル名。最高にダメなネーミング。」

（スコア詳細画面に遷移）

「不健康スコア詳細。食事系が68%、ライフスタイル系が32%。
この比率で次の最終進化が決まります。
このまま食べ続ければ『暴食帝ぶた』、夜更かしに転向すれば分岐する。」

---

### 3:30-4:40 バトルデモ

**画面**: バトル画面

**台詞**:
「さて、この育てたぶたで戦います。」

（ランダムマッチボタン → マッチング待機 → マッチ成立）

「対戦相手が見つかりました。相手は——『ぐうたらぶた』。
生活系パスのぶたですね。ということは……カテゴリ相性で有利！」

（バトル開始 → スキル選択画面）

「20秒以内にスキルを選びます。『暴食タックル』でいきましょう。」

（スキル選択 → ターン実行演出）

「こっちの攻撃——効果抜群！ 食事系攻撃は生活系に1.3倍ダメージ。
**不健康の種類で相性がある。** つまり勝ちたければ、特定分野でもっとダメにならないといけない。」

（1〜2ターン見せる → KO or 優勢の状態で）

「勝ちました！ ランキングポイント上昇。
不健康であればあるほど強い世界です。」

---

### 4:40-5:00 デモまとめ

**操作**: 実機画面からスライドに切り替え

**スライド**: 3つのループ図（シンプル）

```
[記録する] → [ぶた育つ] → [進化する] → [バトルで勝つ] → [もっとダメになりたい]
                                                              ↓
                                                        [もっと記録する]
```

**台詞**:
「ご覧いただいた通り、
記録する → 育つ → 進化する → 戦って勝つ → もっとダメになりたい。
このループが回り始めたら、人は止められません。

以上、ライブデモでした。」

|---|------------|-------------|
| D-1 | 「タケシの1日」導入テキスト | 0:00-0:20 |
| D-2 | （実機画面に切り替え）※スライドなし | 0:20-4:40 |
| D-3 | ゲームループ図（1枚で完結） | 4:40-5:00 |

**デモ中のスライドは最小限。画面が主役。**

---

## デモ失敗時のリカバリー手順

| 障害 | 対応 |
|------|------|
| アプリがクラッシュ | 「ぶたも寝落ちすることがあります（笑）」→ バックアップ動画に切り替え |
| ネットワーク不通 | テザリングに切り替え。それでもダメならバックアップ動画 |
| マッチングで相手が見つからない | 別端末で事前にマッチング待機させておく。最悪「フレンド対戦」で代用 |
| 進化が発生しない | 事前にポイントを進化ギリギリに調整しておく。最悪adminで強制調整 |
| 画面が小さく見えない | 「拡大しますね」とズーム。または事前に文字サイズ最大に設定 |

---

## デモで審査員の心を掴むポイント

1. **ぶたの喜びリアクション** — 不健康記録時にぶたが嬉しそうにすることで会場が笑う
2. **3タップの速さ** — 「はい、もう終わりました」の軽さを強調
3. **進化演出** — 最もビジュアルインパクトがある瞬間。ここで間を置く
4. **スキル名の面白さ** — 「暴食タックル」「満腹バリア」で笑いを取る
5. **バトルの相性** — 「不健康の種類で相性がある」で「なるほど」と思わせる
6. **最後のループ図** — デモで見たことが1枚の図に収まる気持ちよさ
