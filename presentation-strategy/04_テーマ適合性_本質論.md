# 質疑応答対策: ゲーム性×テーマ適合性の本質論

## ビジョナリーステートメント（これが全ての回答の背骨になる）

> **「ぶたそだて」は、人間の罪悪感を燃料に変えるエンジンである。**
>
> 全てのヘルスケアアプリは「正しさ」で人を動かそうとし、失敗してきた。
> 我々は逆だ。「ダメさ」を肯定し、記録させ、可視化し、競わせる。
> ユーザーは気づかないうちに、自分の不健康を「育てる」快楽に溺れていく。
> これが「人をダメにする」の本質——自分がダメになっていくことを、楽しめてしまう構造を作ること。

## 核心の問い: なぜ人は本当にダメになるのか

### 人間の3つのプリミティブな欲求を同時に刺激する設計

```
1. 育成欲（ナーチャリング本能）
   → 自分のぶたが可愛い。育てたい。もっと太らせたい。
   → 親が子を育てるのと同じ脳の報酬系を使っている

2. 収集欲（コンプリート衝動）
   → 6種類の最終進化。全部見たい。暴食帝ぶた、夜食神ぶた...
   → 「あと1つ」の中毒性。ポケモンと同じドーパミン回路

3. 承認欲（ソーシャル比較）
   → バトルで勝つ = 自分のダメさが「強さ」になる
   → 不健康であるほど強い。逆転した価値体系での優越感
```

### なぜこの3つが「人をダメにする」のか

**通常のアプリ**: 正しい行動 → 報酬 → 正の強化
**ぶたそだて**: ダメな行動 → 報酬 → **ダメな行動の正の強化**

つまり、このアプリは**不健康行動そのものに報酬を与える行動経済学的装置**。
使えば使うほど、不健康な行動に対する心理的ハードルが下がっていく。

## 質疑応答: CEOレベルの回答テンプレート

### Q:「これで本当に人はダメになるんですか？」

**回答**:

「はい。しかも自覚的にダメになります。それがポイントです。

皆さん、深夜2時にカップラーメン食べたことありますよね？（間）
あの瞬間、罪悪感を感じましたよね。でも美味しかったですよね。

ぶたそだてはあの罪悪感を**報酬に変換**します。
深夜ラーメンを記録すると、ぶたが嬉しそうに太る。ポイントが入る。レベルが上がる。
次に深夜ラーメンを食べるとき、罪悪感ではなく**ワクワク**を感じるようになる。

これは行動心理学でいう**オペラント条件づけ**です。
不健康行動に正の強化子（ぶたの成長）を結びつけることで、
行動の発生頻度が上がる。人は構造的にダメになっていきます。

しかも——バトルシステムがある。
自分のぶたが強くなるほどバトルで勝てる。
つまり**不健康であればあるほど、社会的に報われる世界**を作った。
この逆転した価値体系に入り込んだ瞬間、人はダメになることを止められなくなります。」

### Q:「既存のヘルスケアアプリとの違いは？」

**回答**:

「根本的に設計思想が逆です。

既存アプリの失敗を数字で言います。ヘルスケアアプリの30日後継続率は平均**6.5%**。
なぜか。人は「正しいこと」を続けるのが苦手だからです。
義務感は最も脆い動機づけです。

ぶたそだてはこの問題を**ゲーミフィケーションの逆転**で解決しました。

|  | 従来のアプリ | ぶたそだて |
|--|------------|----------|
| 記録する行動 | 健康な行動 | 不健康な行動 |
| 記録の動機 | 義務感 | 快楽 |
| 継続の仕組み | 罰（記録しないと怒られる） | 報酬（記録するとぶたが育つ） |
| ユーザー心理 | 「やらなきゃ...」 | 「やっちまった！記録しよ！」 |

人間は「やるべきこと」より「やりたいこと」を続けます。
我々はヘルスケアアプリの構造的欠陥を、人間の本能に寄り添うことで解決しました。」

### Q:「ゲーム性についてもう少し詳しく」

**回答**:

「3つのループが噛み合う設計です。

**ループ1: 日常ループ（毎日）**
不健康行動の記録 → ポイント獲得 → ぶたの成長を確認
これは『たまごっち』の世話ループと同じ。毎日開く理由を作る。

**ループ2: 成長ループ（数日〜週）**
レベルアップ → 進化 → 新スキル獲得 → 新しい見た目
6つの最終進化パスがあり、あなたの「ダメさの傾向」で分岐する。
暴食が多ければ『暴食帝ぶた』、夜更かしなら『不夜城ぶた』。
自分だけのダメさのアイデンティティが形成される。

**ループ3: 対戦ループ（随時）**
リアルタイムバトル → 勝敗 → ランキング → もっと強くなりたい
不健康であるほどステータスが高い。つまり勝ちたければ、もっとダメにならないといけない。

この3つのループが、**短期（今日）・中期（今週）・長期（ランキング上位）**の
全ての時間軸でユーザーをダメにし続ける構造です。」

### Q:「退化システムがあるということは、健康になったら弱くなる？」

**回答**:

「はい。これが最もダメにするポイントです。（笑）

健康的な行動をしてしまうと、ポイントが減ります。
ポイントが減るとレベルが下がり、進化が退化に戻る。
育てた『暴食帝ぶた』がただの子豚に戻る。

想像してください。3週間育てたぶたが退化する瞬間を。
人はそれを防ぐために——つまり**ぶたを守るために**——不健康を続ける。

これはゲームデザインでいう**サンクコスト効果の応用**です。
今まで積み上げた不健康ポイントを失いたくないから、
健康的な行動を取ることに心理的抵抗が生まれる。

本来ならジムに行けるのに、ぶたのために行かない。
本来なら野菜を食べられるのに、ぶたのためにラーメンを選ぶ。
これが**構造的に人をダメにする**ということです。」

### Q:「倫理的な問題はありませんか？」

**回答**:

「素晴らしい質問です。真面目に考えました。

まず前提として——このアプリは**自覚的なエンタメ**です。
ユーザーは「ダメになっている」と自覚した上で楽しんでいる。
ゲーム内で人を殺しても殺人にならないのと同じ構造です。

しかしそれだけでは不十分だと考え、2つの設計判断をしました。

1つ目。ヘルスデータ連携で**客観的な健康状態を可視化**します。
ゲーム化された不健康と、リアルな健康データを並置することで、
ユーザーが「遊び」と「現実」の境界を見失わない設計です。

2つ目。退化システムは逆に言えば**健康に戻れる安全弁**でもある。
ゲームを辞めたくなった時、健康的に暮らせば自動的に「卒業」できる。

我々のスタンスは明確です。
**人をダメにするが、壊しはしない。** ギリギリの堕落を、最高のUXで提供する。」

### Q:「ユーザーが飽きない工夫は？」

**回答**:

「3つの時間軸で飽きさせない設計です。

**短期（今日）**: 毎日の行動記録。ぶたの反応が見たくて開く。
ヘルスデータの自動同期で、寝坊や運動不足を自動検出してポイント化。
朝起きたら既にぶたが成長している。これが毎日のフックです。

**中期（1〜4週間）**: 進化イベント。6つの最終形態×スキル習得。
どのぶたになるかは行動パターン次第。自分だけの育成ルートを辿る好奇心。

**長期（月〜）**: バトルのランキング。全国のダメ人間との競争。
Eloレーティングで実力が拮抗する相手とマッチする。勝ちたければ、育てろ。育てるには、ダメになれ。

そしてソーシャル——フレンドのぶたが進化したら対抗心が生まれる。
あいつに負けたくない。あいつよりダメになりたい。
これが**ダメさの軍拡競争**です。」
